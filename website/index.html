GOOD TO KNOW

下载前，
再了解一点。

我的系统可以运行吗？

当前发布面向 Ubuntu 22.04 及以上的 amd64（x86_64）系统。暂未提供 ARM、Windows 或 macOS 客户端；其他 Linux 发行版的兼容性需要自行验证。

所有软件都会通过镜像下载吗？

EdgeOne 镜像覆盖 UManager 的更新数据与 UManager 自身安装包。受管软件继续使用各自官方来源，不是所有软件都经过 UManager 镜像。

会在后台自动安装或删除软件吗？

后台队列负责下载。系统级安装、更新和卸载需要管理员复核和再次确认。默认卸载保留个人数据；可选彻底清理需要预览并确认清单。

遇到问题或者想参与开发？

可以到 GitHub Issues 反馈问题，或阅读 开发指南。源码公开，欢迎审阅与贡献。
